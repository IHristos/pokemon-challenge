In diesem Ordner befindet sich eine Word-Datei mit der vollständigen Dokumentation zum Projekt und zum Repository.

Das Projekt ist außerdem auf Vercel online verfügbar. Sie können die Anwendung direkt nutzen, ohne etwas herunterladen oder installieren zu müssen:

https://pokemon-challenge-mpq930sab-ihristos-projects.vercel.app

Möchten Sie das Projekt lokal auf Ihrem Rechner ausführen, gehen Sie bitte wie folgt vor:

1. Öffnen Sie ein Terminal und navigieren Sie in das Root Verzeichnis des Repositories.
2. Führen Sie den Befehl `npm install` aus, um alle benötigten Abhängigkeiten zu installieren.
3. Nach erfolgreicher Installation starten Sie das Projekt mit `npm start`.
4. Öffnen Sie Ihren Browser und rufen Sie die Adresse http://localhost:5173/ auf, um die Webanwendung zu sehen.
